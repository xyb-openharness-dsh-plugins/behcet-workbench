# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：成年白塞病患者及其授权代记者

场景：整理疑似、确诊及长期随访中的发作、检查、治疗和多科就诊资料，准备复诊问题。

核心流程：
1. 建立患者档案或由授权代记者记录
2. 记录发作与来源资料并核对
3. 查看随时间变化的检查、治疗和症状
4. 选择资料和问题准备复诊

完成结果：患者能核对和回顾自己的记录，按选择整理复诊资料，并查到原始来源。

初始布局选择：business-first
