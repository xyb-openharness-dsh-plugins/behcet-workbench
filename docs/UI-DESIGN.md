## 4. 设计方案

- **信息优先级**：①我这次要记什么（发作/症状/资料入口）②我记过什么、来源在哪（时间线与回源）③下次复诊带什么（选择与预览）。医学解释性内容一律位于第②层以下，不生成第③层判断。
- **业务容器宽度/宿主布局/收折行为**：业务区居中为主区域；原生 Agent 面板在**右侧**，默认 35%，可调范围 **25–45%**；窄屏下面板改为覆盖/切换，不挤压业务区（参考 `prompts/DSH-AGENT-PANE-INTEGRATION.md`，宿主能力**未实测**）。
- **语义 token、字体/大字、颜色对比、间距、组件**：**待原型阶段产出**（`assets/tokens.css` 尚未按本仓主色改写）；约束来自 starter `docs/30-RESPONSIVE-RULES.md`：正文字号 12.5–15px、触控目标 ≥44px、对比度达 WCAG AA。
- **关键交互、加载/空/错误/成功、结果回顾**：以「AI 候选 → 逐项核对 → 确认入事实层」为默认通道；手工通道收在卡片「⋯ 更多」；**每页显式编辑入口 ≤1、表单 ≤6 字段**（`INTERACTION-DESIGN.md` §三）。
- **信息分层**：主任务常显；低频配置与说明默认折叠；教学提示用 💡 且不阻断主任务。
- **阻断错误及必要确认的直接可见位置**：就地在触发控件旁显示，不用全局弹窗打断。

## 5. 设置入口 / 全局位置

设置从顶栏进入，含四个分区：**患者资料目录**、**授权与隐私**（代记授权与撤回、私密标记及导出/摘要的选择；私密记录当前禁止进入 AI，例外尚未决定）、**云解析授权**（发送前告知服务方/原件/用途，可撤回）、**临床参考数据包**。
API 凭据只显示来源与「已配置」，**不显示明文**。云端授权说明与解析失败降级：失败时保留本地原文与已确认候选，**不静默重试**。
全局资料目录/会话绑定指示器：位置、各状态与真实判定源、非颜色提示、切换中与窄面板表现——**待原型阶段产出**，参考 `docs/09-WORKBENCH-STATUS.md`。

DSH 原生 AI 对话：顶栏拉起按钮与状态文案、面板默认开关、独立隐藏/重开且保留页面与草稿状态、宽度默认值/最小值/最大值及鼠标/触控/键盘调节、偏好存储位置——**以上全部未实测**；宿主能力未核实项标「未验证」并写降级方案（引用 `prompts/DSH-AGENT-PANE-INTEGRATION.md`）。
