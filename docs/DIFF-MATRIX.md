## 0. 一句话

白塞病不是「换了器官名的肿瘤」：**肿瘤骨架是「分期 → 线序 → 复发/转移」，白塞病骨架是「复发—缓解病程 × 多器官受累 × 多科并行就诊」**。因此本项目与成熟基准的差异不是配色和文案，是**一等实体、一级功能线和安全红线的三处结构性不同**（第 5 节 D1–D10）。

本次对比能给出的确定结论只有两条：

1. 基线（乳腺 v0.13.5）的**功能线数量与二级结构**可以作为本项目候选树的量级参照（8 个一级 / 20 个以上二级）；
2. 本项目在原样复用家族标准一级名（看板 / 病情整理 / 病情一图秀）之外，**其余 5 条功能线必须另起**，因为基线里没有「发作」「器官与专科」「用药前筛查」这三个问题域。

一级重名率、功能线覆盖、私密项清单**都只有草案值**，G1 定稿后必须重测（第 2.3、6 节）。

## 3. 功能线逐条走查（L1–L10 家族池）

26 号 §2 要求「每一条都要显式回答上 / 不上 / 为什么，沉默漏掉是最常见的失误」。下表逐条回答。

| 线 | 基线（乳腺 v0.13.5）怎么做 | 本项目（候选 / 设计假设） | 判定 | 理由 |
| --- | --- | --- | --- | --- |
| L1 看板 | 独立一级「看板」，一屏卡片 | 独立一级「看板」 | **上（同构）** | 「我现在整体什么情况」是通用问题，骨架可复用，内容全换 |
| L2 疾病本体 | 独立一级「临床」内做「病理·分子档案」 | **拆成两条一级**：「发作与病程」+「器官与专科」 | **上（拆线，刻意不同）** | 肿瘤的本体是「一个病灶 + 一套分期」；白塞病的本体是**复发—缓解的发作过程**加**多器官是否受累**，两者不同源，合在一条线里会互相稀释（26 号 §4.1 同款判断：HCC 的肝 × 瘤拆两条） |
| L3 治疗与决策 | 独立一级「临床」做「治疗历程」 | 独立一级「治疗与用药」 | **上（换内容）** | 保留骨架；新增肿瘤基线**没有**的节点「用药前检查与注意」（生物制剂类治疗前的感染筛查与告知，**待临床核验**） |
| L4 指标分析 | 「指标检测」子页：分组卡 + 分级徽章 + `needsUln` | 保留「指标检测」子页（在病情整理内）+「病情一图秀」 | **上（分级口径待核）** | 结构照家族标准（16/23/24 号）；**是否引用 CTCAE v5.0 分级必须 M1 与临床核验后再定**，先确定出处和单位/方法可比性，阈值提示须经核验，**不做疾病活动度评分** |

| D2 | 一等实体 | 检查/用药/症状记录 | 新增一等实体 **`episode`（发作）** | 「这次溃疡从哪天开始、几天好、吃饭受不受影响」是本病种最基本的一次记录；肿瘤骨架里没有对应实体 |
| D3 | 专科结构 | 单癌种的科室链 + MDT | **多科并列**：风湿 / 眼科 / 皮肤 / 消化 / 血管 / 神经 / 口腔黏膜（方向） | 候选需求是「向不同科室说清时间顺序」，不是一条科室链 |
| D4 | 治疗前节点 | 新辅助/辅助/维持等肿瘤语义 | **用药前检查与注意**节点 | 生物制剂类治疗前的感染筛查与告知可能涉及的检查准备（**待核**） |
| D5 | 安全红线 | 术后伤口、淋巴水肿、骨髓抑制类 | **眼 / 消化道 / 血管 / 神经**方向 | 同上，**待临床核验后才写可读短语**；现在只登记主题 |
| D6 | 试验入口 | 有真实登记库则开「试验线索」 | **不开** | 未查询、未建快照，不能把「未搜索」说成「没有试验」 |
| D7 | 私密范围 | 心理与亲密 | 心理与家庭、生育·性健康、代记授权、家庭可见性 | 目标人群含育龄患者与授权代记者，授权与可见性本身就是隐私问题 |
| D8 | 阈值来源 | CTCAE v5.0 分级 + 标志物不分级 | 分级适用性待临床核验；×ULN 需化验单自带上限 | 本病种的主要用药与监测场景与肿瘤治疗毒性不同，是否沿用 CTCAE 需临床核验（**待核**） |
| D9 | 命名与分组 | 8 个一级名 | 只保留 3 个家族标准名（看板 / 病情整理 / 病情一图秀），其余 5 条另起 | 26 号 §4.1：命名照抄会让「看起来做了」掩盖「其实没做」 |
