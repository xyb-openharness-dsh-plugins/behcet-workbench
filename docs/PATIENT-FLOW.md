# 患者流程草案

> **文档编号**：PATIENT-FLOW ｜ **版本**：`v0.1.0-draft.1`（2026-11-02）
> **访谈 0 次，临床审核 0 次；用户验证和原型确认均未进行。**下列就诊、自查、复查过程及困难时刻均为设计假设，不是患者引语或实际观察。服务对象为成年白塞病患者及授权代记者，覆盖疑似至长期随访。

以下从患者任务反推候选页面，具体需求、名称、顺序和断网能力均待验证。工作台用于整理和回源，不诊断、不决定治疗；求助内容需临床审核，未经审核不得作为判断依据。证据与缺口见 [用户研究](USER-RESEARCH.md)，场景及验收见 [场景候选](SCENARIOS.md)。

## 三条假设路径

### 一次就诊：整理跨科资料

假设困难时刻：候诊时想不起口腔、眼部症状和不同科室检查的时间。

`复诊准备 → 选择资料与问题 → 预览并回源 → 选定的就诊材料和问题清单`

患者或授权代记者选择已有记录；私密资料默认排除，预览呈现实际选择。没有原件时允许保留缺项，不编造内容；不同来源冲突时并列显示，不代替医生判定。导出失败时保留选择并允许重试。对应 S02、S09、S12，候选验收 AC02、AC09、AC12。

### 一次自查：记录新变化

假设困难时刻：症状出现时精力有限，难以完整描述过去的发作。

`发作记录 → 填写部位与已知时间，必要时暂存 → 可回顾的记录；需要求助时查看经审核的信息`

允许不确定时间和稍后补充；未检测不等于阴性。保存失败应明确提示并保留可恢复的输入。求助信息的内容、触发与离线可用性均待审核及实测；未经审核时标明不可用于判断。**「紧急情况联系当地急救服务」为【待核】占位**（同 `SCENARIOS.md`），核销前不得当已审核文案上线。系统不作诊断或用药建议。对应 S01、S03、S08，候选验收 AC01、AC03、AC08。

### 一次复查：回顾既有医嘱和检查

假设困难时刻：复查前想知道上次检查的时间、医生说过什么以及有哪些问题要问。

`医嘱与检查记录 → 时间线及原件 → 选择问题 → 一份复查沟通材料`

患者或代记者登记医嘱原文及其来源，未知日期保持未知；系统不生成医学复查间隔。检验值须同时显示日期、单位、方法和原单来源，无法比较的记录不连线。没有既有医嘱时展示空态并允许继续。对应 S06、S07、S10、S12，候选验收 AC06、AC07、AC10、AC12。

## 反推的候选页面

| 页面 | 由哪条路径产生 | 内容与边界 |
|---|---|---|
| 发作与生活影响 | 自查 | 部位、时间、描述、来源和修订；不诊断 |
| 资料与检查 | 就诊、复查 | 原件、检查及来源；缺失与未知分开 |
| 时间线 | 就诊、复查 | 按时间回顾上述记录；可回源，冲突保留 |
| 治疗与医嘱 | 复查 | 医嘱及治疗原文、时间和来源；不建议调整 |
| 复诊准备 | 就诊、复查 | 挑选、问题、预览和导出；私密内容默认排除 |
| 求助信息 | 自查 | 临床审核前仅为待定占位；不得输出诊断 |
| 用药前检查记录 | 复查 | 抄录医生已安排的检查名、日期与来源；**不出缺项结论**（S15） |
| 症状记录 | 自查 | 症状、起始、影响与来源；不打器官归属标签、不作医学判断（候选归页为「发作与病程 / 症状记录」；回看与更正尚未实测） |
| 授权与隐私设置 | 三条路径共用 | 授权代记者、记录主体、私密标记和出口选择；可见范围与撤权规则见 `SPEC.md` §代记者的可读范围（未实测） |

以上是候选信息架构，并非已签认的交互设计。用户明确选择资料目录；云解析前须告知原件离开本机并由用户触发，解析结果须经核对。断网、窄屏、键盘、低精力、保存及导出失败均需在后续交互设计和原型中逐项验证。患者流程按具体时刻组织，器官和科室只是可选筛选维度，避免照搬医生工作流。
