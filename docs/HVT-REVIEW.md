## 1. 方法与口径

- 疾病轴：填写本病种在十条轴上的差异（见技能 references/hvt-derivation.md）。
- 打分：V/S/F 各 1–3；HVT 门槛 V≥2 且 S≥2；优先级 P = V×S×(5−C)。
- 五层：S/M/F/I/A 各 0 或 1；每层判据见 references/five-layer-check.md。
- 脚本初值：**命令与输出路径待填**（`scripts/check-hvt-*.mjs` 尚未建立）；报告中的 C 均经人工复核。
- **可复现证据源（本轮已就绪）**：`docs/UI-DESIGN.md` §2（分类法对照）、§2.1（孤儿页清单）、§3（四段自检）、`docs/DIFF-MATRIX.md` §2.3（重名率复现命令）、`docs/INTERACTION-DESIGN.md` §四（IP1–IP11 现状）。

### 疾病轴与病程节点（初稿，非临床审核）

本项目不是肿瘤工作台：十轴保留原编号供核对，但不套用肿瘤分期、转移或固定疗程。E08 指国家指南第9章原件，具体来源及图文差异见 `CLINICAL-DATA-2026.md`；医学背景不证明这些任务是患者需求。每行场景均为待访谈假设，恢复路径参见 `SCENARIOS.md` 的通用恢复候选。

| 轴 | 白塞病相关背景或适用性 | 病程节点 → 触发 → 想完成的事 → 产物 | 对应及缺口 |
| --- | --- | --- | --- |
| A1 病理与分子分型 | 不照搬肿瘤分型；E08 有临床诊断及检查内容，不作为个人自测 | 疑似或确诊后 → 多份报告术语不同 → 保留原文并带去询问 → 带来源的问题与材料 | S02/S12；具体报告术语和患者需求待访谈 |
| A2 器官与解剖 | E08 涵盖口腔、生殖器、眼及其他系统；个体表现不同 | 疑似至随访 → 溃疡反复出现 → 记录部位及时间 → 发作记录 | S01；隐私默认保护，记录方式待验证 |
| A3 分期 | 肿瘤分期不适用本项目边界；不自行分型或判活动度 | 跨科就诊 → 不同文件描述不一致 → 分别保留原文 → 可回源资料 | S02；不同表述不能自动合并 |
| A4 治疗组合 | E08 按受累部位讨论临床治疗；不推断每个人都采用某顺序 | 治疗变化后 → 难以回忆原医嘱 → 整理药名、日期与来源 → 治疗记录 | S06/S07；不得推荐或调整治疗 |
| A5 复发转移 | 肿瘤转移轴不适用；E08 描述多系统表现，发作与器官事件不能自动认定因果 | 随访 → 症状与检查发生在不同时点 → 分别记录 → 并列时间资料 | S05；不得自动认定复发或因果 |
| A6 治疗安全 | E08 包含治疗注意事项；药品具体适应证及风险需另核原件 | 治疗前 → 医生已安排检查 → 记录原文与日期 → 可回看清单 | S15；不判缺项或适宜用药 |
| A7 功能与生活 | 生活影响为需求假设；本项目无患者访谈支持其频次 | 长期生活 → 疲劳或疼痛影响日常 → 用自己的话记录 → 讨论材料 | S08；病种特异性及负担待访谈 |
| A8 检查与随访 | E08 有检查内容，但没有独立长期随访方案；不生成复查周期 | 复诊前 → 多次检验单位或方法不同 → 保留原单语境 → 可核对的记录 | S10；可比性判定权待审核 |
| A9 急性症状信息 | E08 不是患者分诊指南，求助短语尚无临床审核 | 新眼部或神经相关症状 → 想找到可靠求助信息 → 查看审核状态 → 待审核占位 | S03；不上线未经审核的分诊内容 |
| A10 代记与隐私 | 授权代记者是用户选定主体；实际权限需求未访谈 | 需他人协助记录 → 选择授权范围并标记记录者 → 可追溯记录 | S11；撤权与可见范围须用户验证 |

以上是十轴各一个示例，不是完整轴×病程网格，也未证明唯一性或高价值；S01–S15 尚需逐条独立审查及评分。
