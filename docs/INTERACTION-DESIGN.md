## 一、总原则（按本项目改写；签认前仍属草案）

1. **AI 协助可作为候选默认通道（待患者确认）**：说一句话 / 拍一张照片 / 交一份 PDF → 产出**结构化候选** → 患者逐项核对（每项有「不对，改一下」直达入口）→ **确认才入事实层**；拒收候选**零副作用**。AI 说错是常态预期，候选落「待核对」，不落「已保存」。
2. **手工通道可及及入口位置均为待患者确认的设计选择**：手工入口统一收在卡片「⋯ 更多」；**每页显式编辑入口 ≤ 1**；**每张表单 ≤ 6 字段**；数字输入用**键盘组件**不用文本框；禁止平铺长表单。
3. **删除 = 更正**：只新增版本，不物理删除；界面语言统一「**改这一条**」；**全站禁止**出现「删除记录将不可恢复」式文案；更正后旧值必须能在版本链看到。
4. **回首页一步可达**：二级页返回 / 顶栏品牌 / 完成 Toast 内嵌「回到看板」，完成后**无死端**。
5. **患者主语**：工作台**不做**诊断、分型、疾病活动度判定、用药推荐、预后或因果判断；AI 只整理与复述患者自己的记录，不代替患者发言（AI 协助入口按 34 号契约显式触发受守卫的一键发送）。
6. **私密与代记是结构属性**：私密内容对**导出、AI 上下文、摘要**三个出口默认排除；授权代记者写入的每条记录带**代记标记**与授权依据，患者可撤回授权（不在本文展开，见 `docs/SPEC.md` §数据和安全边界）。
7. **零临床审核的纪律**：任何医学短语（红旗症状、用药注意、复查节奏）在**核销前只写主题占位**，不写患者可读结论；核销记录进 `docs/HVT-REVIEW.md`（当前空模板）。

## 三、CRUD 双通道矩阵（每个可写实体一行）

| 实体 | AI 协助（候选默认） | 手工（收敛入口 / 字段数 ≤6） | 说明与红线 |
| --- | --- | --- | --- |
| **发作记录**（`episode`） | 说一句 → 候选（部位 / 开始日期 / 疼痛 / 进食影响 / 来源=本人叙述） | 「⋯ 更多」→「手工补一条」；≤6 字段；疼痛用三态或滑条，日期用键盘组件 | 结论照抄患者叙述；「算不算发作」由患者自己定，**不自动判定**；变更留痕不删旧 |
| **症状记录**（不适/乏力/发热/关节） | 说一句 → 候选（症状 / 起始 / 影响） | 同上 | **不打器官归属标签**，患者可选「先不选」；没有医学判断 |
| **检查资料**（`document` + 派生指标） | PDF / 照片 → 候选（指标名 / 值 / 单位 / 参考上限 / 日期 / 来源） | 「⋯ 更多」→「手工补一条」；≤6 字段；数字用键盘组件 | 结论照抄原文；不同单位/方法**不连成一条趋势**。**【待核】×ULN 类阈值提示**：初版把它写成硬要求（「必须用化验单自带参考上限，借不到就不断言」），但它是一条**第 3 层判断**，与 `SPEC.md` 边界清单「不作分级」相邻，**核销前不得实现**。若将来核销，口径限定为：仅用化验单自带上限做纯算术比对、借不到上限就不显示、**不得据此给出严重程度、分级或处置建议**。核销记录进 `HVT-REVIEW.md` |
| **用药记录**（`medication`） | 说一句 → 候选（药名与剂量**原文抄录** / 起止 / 感受） | 「⋯ 更多」→「手工补一条」；≤6 字段 | 不提示自行调整；剂量原文与来源必留；变更=更正链 |
| **用药前检查记录**（`prescreen`）【待核】 | **—**（红线：AI 不生成、不推断「应该做哪些检查」，也不比对出缺项） | 「⋯ 更多」→「手工补一条」；抄录检查名原文、日期、来源、所属治疗 | **纯抄录**。初版此行为「用药前待办（资料缺项清单）」并由系统生成缺项——「缺某项」本身是临床结论，已改；**禁止出现**「缺项」「还差几项」「可以开始用药」类文案。场景 S15 / FN13 / AC15 |
| **复诊问题**（`question`） | 由**选定且非私密**的记录改写成问句候选 → 逐条核对 | 「⋯ 更多」→「手工加一条问题」 | **优先级条款（2026-11-02 补）**：私密记录**不进 AI 上下文**，因此**不能作为 AI 改写来源**——初版写「由选定记录改写成问句候选」并称「私密记录衍生的问题默认不带原文」，隐含 AI 已读到私密原文，与原则 6 及私密行红线冲突。现定为：**私密行红线优先于本行的 AI 改写**；私密话题的问题只能由本人逐字输入（或本人逐字确认的转写）。导出的内容与勾选一致 |
| **代记记录**（`proxy_entry`） | 代记者说一句 → 候选（内容 + 代记徽章 + 授权依据） | 手工补一条（同徽章） | 代记者身份与授权必选；患者可撤回；**代记者不等于另一个患者**，可见性独立设置 |
| **私密记录**（心理 / 生育 / 性健康） | **—**（红线：不 AI 生成、不 AI 推断私密话题；仅接受本人输入或本人逐字确认的转写） | 本人输入 | 对**导出 / AI 上下文 / 摘要**三个出口默认关闭；私密是数据结构属性，不是界面开关 |
| **就医边界提示**（红旗短语）【待核】 | **—**（红线：不做分诊、不判断严重程度） | 不适用（由维护者按核销后的短语写死） | 未核销不上线；上线后仍不承担判断责任。**含「出现紧急情况应联系当地急救服务」一句在内**：该句在 `SCENARIOS.md`、`PATIENT-FLOW.md`、本文件均为**占位**，不得当已审核文案使用 |
| **授权记录**（代记授权与撤回） | 不适用（本人操作） | 设置内本人操作 | 撤回后写入被拒并留痕；不在本文展开 |

**不做 AI 通道的实体一律写「—」并写明红线理由**；评审补入的实体行必须留痕，**沉默漏实体算失误**（28 号 §3.3）。
